# Movie Recommendation System 🎬

## Project Overview

This project is a simple Movie Recommendation System developed using Python.

The system recommends movies based on the user's preferred genre. Users can choose a genre such as Horror, Romance, Comedy, Action, Thriller, Sci-Fi, Fantasy, Mystery, Adventure, Drama, Crime, Animation, Documentary, Historical, Musical, Family, War, Superhero, Psychological, or Sports.

## Features

- 20 different movie genres
- 10 movies available for each genre
- User-friendly command-line interface
- Recommends movies based on selected genre
- Handles invalid genre input

## Technologies Used

- Python

## How It Works

1. The program displays the available movie genres.
2. The user enters their preferred genre.
3. The system checks the selected genre.
4. Movies from that genre are displayed as recommendations.

## Example

User enters:

Horror

The system recommends:

- The Conjuring
- Annabelle
- Insidious
- The Nun
- It
- The Exorcist
- Hereditary
- Sinister
- A Quiet Place
- Scream
