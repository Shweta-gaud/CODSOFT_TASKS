# CodSoft AI Chatbot

## Project Overview

This project is a simple rule-based AI chatbot developed using Python.
It provides basic responses to user messages and can perform simple
tasks such as showing the current time and date.

## Features

- Greeting responses
- Current time
- Current date
- Jokes
- Motivational messages
- Course-related information
- Basic conversation
- Help command
- Clear chat option
- Simple graphical user interface

## Technologies Used

- Python
- Tkinter
- Datetime module
